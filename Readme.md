# ShowKuromi (Glyphs 3 / 4 Reporter Plugin)

Glyphs 3 および 4 の編集ビュー（Edit View）上で，グリフの黒みの幾何学的重心（Center of Mass）および仮想ボディ（Em Square）に対する黒み充填率（面積比）をリアルタイムに計算・描画する Reporter プラグインです．

## 主な機能と特徴

### 1. 正確なモーメント・面積計算
- fontTools.pens.statisticsPen.StatisticsPen を用いて，Green の定理（線積分）に基づき輪郭の 0次モーメント（面積）および 1次モーメント（重心 $X, Y$）を高精度に算出します．
- layer.completeBezierPath を介して，複数パスはもちろんコンポーネント（複合グリフ）も正確に展開・合成した状態で計算対象に含めます．

### 2. 基準線・ガイド・幾何中心の可視化
- 仮想ボディ（Em Square）と中心マーカー: UPM・ディセンダ基準の仮想ボディ枠線と，中心を示すブルーのダイヤマーカー．
- EM中心十字線: 仮想ボディ中心を通る薄いシアン・ブルーの直交十字線．
- 重心通過ライン: 重心を通る薄い赤の直交十字線．
- 字面中心（BBox Center）: 重心マーカーと同等サイズ（半径7.2pt相当）のアンバーオレンジのダイヤ十字マーカー．
- 偏差ベクトル & 差分バッジ: 仮想ボディ中心から重心マーカーへ向かう矢印付き結線と，マーカー近傍の差分バッジ（ΔX: +40, ΔY: +21）．
- 重心マーカー: 鮮やかな赤の二重円十字マーカー．
- 情報HUDパネル: 各グリフ下部に黒み面積，充填率，重心座標，EM中心差に加え，仮想ボディ中心で4分割した各象限（左上・右上・左下・右下）の黒み面積・充填率・構成比を日本語で表示．

### 3. 右クリックコンテキストメニュー（表示項目の切り替え）
編集画面上での右クリックから，各表示項目のオン/オフを個別に切り替えられます．
- [x] 重心十字線を表示 (Show Center Crosshair)
- [x] EM中心の十字線を表示 (Show EM Origin Crosshair)
- [x] 偏差ベクトル線を表示 (Show Delta Vector)
- [x] 重心の偏差情報を表示 (Show Deviation Badge)
- [x] 字面中心を表示 (Show BBox Center)
- [x] 四象限の黒み情報を表示 (Show Quadrant Blackness)
- [x] 情報ボックスを表示 (Show Info HUD)

※ 各設定状態は Glyphs.defaults に永続化され，再起動後も維持されます．

## インストール手順と動作確認方法

1. 一度 Glyphs を終了 します．
2. ShowKuromi フォルダ内の ShowKuromi.glyphsReporter をダブルクリックしてインストールします（またはプラグインフォルダ内の既存プラグインを置き換えます）．
3. Glyphs を再起動 します．
4. 編集画面の 表示（View）メニュー > 重心と黒みを表示（Show Kuromi） にチェックを入れます．
5. 編集画面上で右クリックし，コンテキストメニューから各ガイドラインやバッジの表示/非表示を切り替えられることを確認してください．
